## 显示合同

共用合成器 `mockupStudio.ts` 使用显示算法标识 `highlight-power-v1`，写入输出 canvas 的 `data-studio-transfer`，不是新的持久化 render spec 版本，也不是物理曝光。

- 产品灯或背景图层灯大于 1：产品保留原生 `contrast(1.04)`，然后 RGB 分别映射为 `round(255 * (channel / 255) ** (1 / light))`；Alpha 原值保留。set/ground 使用相同曲线但不加产品对比度。
- 默认和调暗（小于等于 1）沿用原合成器路径。平面背景填色仍按原背景逻辑；不对整张合成图统一加曲线。
- GroundedShot、原图灯箱、下载共用实现。没有 ground 的旧单也改走同一 canvas，不再保留 CSS brightness 分叉。旧单白桌白墙因此跟随下载的绘制背景，而不是原先 CSS 平面底色；不能声称旧 CSS 展示逐像素不变。
- 每个目标 context 只保留一个可复用临时 canvas；不缓存每个滑条位置的全尺寸图片。预览按其 backing 尺寸处理，原图和下载按源尺寸处理。
- 小预览先缩放再映射，全尺寸导出先映射再由显示端缩放，非线性与重采样顺序不同。因此只承诺同尺寸同输入共用算法，不声称不同分辨率逐像素相同。
- 原生 filter 不支持时，提亮仍执行软件曲线；默认对比度及调暗维持既有无滤镜回退，不宣称该路径与有滤镜路径像素一致。
- 无法取得临时 context 或读取像素时抛错，页面清空失败画面并显示错误，不静默退回截白公式；合成器 finally 恢复 context 状态，下载不能导出被当成成功的失败结果。
- GLB 曝光映射、印刷面读字、Blender 输出均未改。静帧曲线与 GLB 曝光不是同一种色彩变换，不宣称视觉等价。
