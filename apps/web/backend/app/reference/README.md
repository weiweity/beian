# 受控化妆品原料参考词典

`cosmetic_ingredients.v1.json` 是审稿比对的离线参考数据，不是监管目录镜像，
也不是模型训练集。当前只收录审稿单 `ff89a97a1fe3` 涉及的 21 个原料。

## 判定边界

- Excel 原文与 OCR 原文仍是审核结论的唯一直接证据。
- 词典只给出标准中文名、INCI、来源版本和候选解释；仅靠 INCI/别名候选
  不得把缺失项改成“一致”。
- `listed_i_objective_record` 表示被《已使用化妆品原料目录》I 客观收录，
  不表示该原料或具体产品已被监管机构作安全背书。
- CAS、论文俗名、供应商商品名和 OCR 错字只有经过业务人员确认后才能加入；
  它们必须放在独立字段并保留来源，不得混成官方名称。

## 更新流程

1. 以国家药监局/中检院动态发布的《已使用化妆品原料目录》I、II 为主来源。
2. 仅把本公司实际需要的原料加入小范围快照；记录目录版本、检索日期、
   原料序号和原始来源链接，不批量复制整个监管数据库。
3. 每次更新运行 `tests/test_ingredient_lexicon.py`，确认字段完整、名称无歧义，
   并用真实人工签字样本做 L2 评估。
4. 论文、CosIng、供应商 INCI/SDS 只能补充候选别名或 CAS；不得覆盖中国
   监管目录中的标准名称与状态。
5. 只有积累了人工签字的金标后，才评估监督学习/重排；不直接用未核验网页
   数据做强化学习。
